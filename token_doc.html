MookNote 获取增强搜索 Token 说明

本说明用于介绍 MookNote（以下简称"本应用"）增强搜索 Token 的功能范围、获取方式、收费标准及使用注意事项。Token 所解锁的功能均为可选的在线服务，不影响本应用本地记录功能的正常使用。

一、付费功能

以下增强功能需要获取 Token 后使用：

  • 在线影视搜索：搜索影视作品，在线观看，查看详细信息、演职人员等信息条目，以及点击加号直接添加，不用手动录入；
  • 在线书籍搜索：搜索书籍，查看目录、国图信息、网购地址等信息条目，以及点击加号直接添加，不用手动录入；
  • Excel 带图导出：上传本地数据，云端处理完毕后导出带图的 Excel 表，云端只处理数据，不做任何形式的保存。

未来将推出更多优秀功能，如多设备云同步，微信小程序，iOS 和 Mac 端支持等功能。

二、付费原因以及金额

云搜索等在线功能涉及服务器费用、域名费用和维护成本，开发者不求盈利，只求能覆盖一点电费即可。

三、如何获取 Token

（一）加入 QQ 群

开发者会在 QQ 群内不定期发放在线搜索的 Token，如果实在有需要，私聊开发者即可。

（二）填入应用

取得 Token 后，请在本应用"设置 → 在线 API"页面填入并保存，即可使用对应的增强功能。

四、注意事项

  • Token 仅限个人使用；
  • Token 有效期有限，过期后需重新获取；
  • 请勿分享或泄露您的 Token（如果发现有很多很多设备使用的话，会封禁您的 Token）；
  • 搜索响应可能有些慢，但是我会慢慢优化的。
