MookNote 隐私政策

发布日期：2026 年 11 月 8 日　生效日期：2026 年 11 月 8 日

本隐私政策由 MookNote（以下简称"本应用"）运营者制定并发布。本应用是以本地存储为核心的影视、阅读、游戏及笔记记录工具。我们深知个人信息对您的重要性，并将按照法律法规要求和业界成熟的安全标准，采取相应的安全保护措施，尽力保护您的个人信息安全可控。

本政策适用于您通过本应用使用我们的产品及服务。请您在使用本应用前，仔细阅读并充分理解本政策的全部内容。一旦您开始使用本应用，即表示您已充分理解并同意本政策。本应用不强制注册、不强制授权，核心记录功能在离线状态下即可完整使用。

二、我们如何收集和使用您的个人信息

我们遵循合法、正当、必要和诚信原则，仅收集实现产品功能所必需的个人信息。具体情形如下：

（一）本地记录功能（核心功能，无需联网、无需账号）

您主动录入的影视、书籍、游戏、笔记、人物、片单、自定义分类、评分与评论等文字内容，以及您从相册选择或自行保存的封面、截图等图片，均存储于您设备本地的数据库（mooknote.db）及本地存储目录中，不会默认上传至我们的服务器。您不提供上述内容，不影响本应用的正常安装与浏览。

（二）崩溃日志与运行日志信息

为排查和修复应用故障，本应用内置匿名崩溃上报机制。当应用发生崩溃，或您主动提交运行日志时，本应用会向服务器（api.mooknote.iletter.top）发送以下信息：

  • 匿名设备标识（device_hash）：本应用在本地生成并保存的随机标识，不包含设备硬件序列号，亦无法据此识别您的真实身份；该标识不存在时，上报功能不生效；
  • 应用版本号；
  • 设备操作系统类型；
  • 崩溃错误信息及堆栈文本，或您主动提交的日志内容。

上述信息不包含您录入的任何记录内容。崩溃日志在服务器端保留九十日，期满后自动删除；相同签名的崩溃仅上报一次。

（三）意见反馈信息

当您主动使用意见反馈功能时，我们将收集您填写的反馈内容、您选填的联系方式、应用版本号、操作系统类型及上述匿名设备标识。联系方式由您自愿填写，不填写不影响反馈提交。已处理完成的反馈记录在服务器端保留一百八十日，期满后自动删除；待处理记录保留至处理完成。

（四）带图 Excel 导出功能

当您主动使用附带图片的 Excel 导出功能时，导出任务请求（含匿名设备标识、数据类型、语言选项）及相关图片将上传至我们的服务器用于生成文件。所生成文件仅供您本人下载，服务器将定期自动清理任务文件及临时数据，不作其他用途。

（五）在线搜索功能

当您使用影视、书籍在线搜索功能时，本应用会将您输入的搜索关键词发送至相应数据源（vipapi.mooknote.iletter.top 及您配置的第三方数据源，如 TMDB、豆瓣等）以获取搜索结果。相关信息处理同时适用对应数据源的隐私政策。若您自行配置了搜索 API Token，该 Token 仅保存在您的设备本地。

（六）备份与同步功能

  • 本地自动备份：备份文件生成并保存在您的设备本地存储中，不上传。
  • WebDAV 云备份：您主动使用该功能时，需自行填写 WebDAV 服务器地址、账号及密码。上述凭据仅保存在您的设备本地，用于与您自行提供的 WebDAV 服务完成认证与数据传输，我们不收集、不获取该等账号密码。
  • 自建服务器云同步：您主动配置并连接自建或自行指定的同步服务器时，您的记录数据将在您的设备与该服务器之间传输。数据接收方为您指定的服务器，相关处理同时受该服务器服务条款约束。

（七）其他联网行为

本应用启动或使用相关功能时，会从服务器拉取软件更新日志、增强视频校验值等公开配置信息。此类请求仅为下行获取配置，不上传您的个人信息或记录内容。

本应用不采集设备硬件序列号、手机号码、地理位置、通讯录等信息。

三、第三方 SDK 及第三方服务

为实现崩溃监控与性能优化，本应用集成了友盟系列 SDK，由友盟同欣（北京）科技有限公司提供。该 SDK 的信息处理行为同时受其隐私政策约束，详见：https://www.umeng.com/page/policy/。具体情况如下：

SDK 名称使用目的涉及信息类型
友盟 U-App 统计 SDK（umeng_common_sdk） 应用启动次数、页面访问等基础运营统计 设备标识信息（如 OAID 等）、设备型号及操作系统版本、网络状态、应用版本号、崩溃日志、页面性能数据（帧率、加载耗时等）
友盟 U-APM 性能监控 SDK（umeng_apm_sdk） 监控页面流畅度与性能表现，协助定位卡顿问题
友盟 UMCrash 崩溃监控 采集 Java 层及 Native 层崩溃、未预期异常日志

本应用已在友盟侧关闭 ANR 分析、启动分析、内存分析、H5 页面分析及功耗分析等附加采集项，仅保留崩溃采集与页面性能监控。友盟 SDK 不获取您录入的任何记录内容。除上述 SDK 及您主动配置的搜索、同步数据源外，本应用不接入任何广告类、推送类 SDK。

四、应用申请的权限及用途

本应用不会在安装后默认索取敏感权限。相关权限均在您使用具体功能时由系统弹窗征得您的同意，您可随时在系统设置中关闭。拒绝授权不影响其他不依赖该权限的功能。各项权限的具体用途如下：

权限系统权限名称使用目的
网络访问 INTERNET 在线搜索、崩溃上报、意见反馈、备份同步、配置拉取等联网功能
网络状态 ACCESS_NETWORK_STATE、ACCESS_WIFI_STATE 判断网络连通性，供联网功能及第三方统计 SDK 使用
电话状态 READ_PHONE_STATE 供友盟统计 SDK 生成匿名设备标识、区分设备环境使用；本应用自身不读取、不存储通话相关信息
存储及所有文件访问 MANAGE_EXTERNAL_STORAGE、READ_EXTERNAL_STORAGE、WRITE_EXTERNAL_STORAGE 扫描本地字体、备份与恢复数据、将图片保存至设备
照片（Android 13 及以上） READ_MEDIA_IMAGES 从相册选择封面、图片及保存图片
视频（Android 13 及以上） READ_MEDIA_VIDEO 读取系统媒体库中的视频文件供记录关联
音频（Android 13 及以上） READ_MEDIA_AUDIO 读取系统媒体库中的音频文件

本应用不申请相机、定位、通讯录、通话记录、短信、麦克风等敏感权限，亦不存在后台静默获取上述信息的行为。

五、本地存储与同类技术

本应用为本地客户端，不通过浏览器 Cookie 或同类跟踪技术对您进行追踪。本应用仅使用设备本地存储（SharedPreferences 及本地 SQLite 数据库）保存您的设置项、偏好配置及记录数据，该等数据保存在您的设备上，我们不会主动收集。卸载本应用或清除应用数据将删除上述本地数据。

六、信息的共享、转让与公开披露

（一）本应用不向任何第三方出售、出租您的个人信息，不接入广告类、推送类 SDK。

（二）出于崩溃监控与性能统计目的，本政策第三条所述设备及运行信息将共享给友盟 SDK 提供方。该提供方作为独立的个人信息处理者，依据其自身隐私政策处理相关信息。

（三）您的记录数据仅在您主动使用 WebDAV 备份或云同步功能时，传输至您本人提供或指定的服务器，我们并非该等数据的接收方。

（四）我们不会公开披露您的个人信息。除因法律法规规定，或司法机关、行政机关依法提出强制性要求外，我们不会向任何第三方提供您的个人信息。

（五）我们不会将您的个人信息转让给任何第三方。如发生合并、收购、资产转让等导致本应用运营主体变更的情形，我们将要求新的承继主体继续受本政策约束，否则将要求其重新征得您的同意。

七、信息的存储与保护

（一）存储地点：您的记录内容主要存储于您的设备本地；崩溃日志、意见反馈等匿名信息存储于中华人民共和国境内的服务器。

（二）存储期限：本地数据由您自行管理，卸载本应用或删除记录后即从本应用删除；服务端崩溃日志保留九十日，已处理反馈保留一百八十日，导出任务文件定期清理，期满自动删除。

（三）安全措施：匿名设备标识采用随机化方式生成，与您的真实身份无关；服务器采取访问控制、操作鉴权及定期备份等措施，防止信息泄露、毁损或丢失。请您妥善保管设备及自行配置的备份账号信息。

八、您的权利

按照相关法律法规规定，您对您的个人信息享有以下权利：

（一）查阅、复制、更正、删除：您可在本应用内随时查看、编辑、删除全部记录内容；

（二）撤回同意：您可在系统设置中随时关闭已授予的存储、照片、视频、音频等权限，亦可通过不开启备份同步功能、不使用在线搜索及反馈功能，拒绝相应的信息传输；

（三）注销与删除：卸载本应用将停止第三方 SDK 的后续采集，并清除本应用在设备本地存储的全部数据；

（四）对服务端留存的崩溃日志、反馈记录行使查阅、删除等权利的，可通过本政策载明的邮箱联系我们，我们将在核实您的身份后依法处理。

九、未成年人保护

本应用为通用工具类记录软件，不面向未成年人提供专门服务，亦不主动收集未成年人个人信息。若您为未成年人，请在监护人指导下使用本应用，且勿在未经监护人同意的情况下填写或上传个人信息。监护人发现我们在无有效同意情况下收集了未成年人个人信息的，可通过本政策载明的邮箱联系我们予以删除。
